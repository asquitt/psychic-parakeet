# Learning Resources

## 📚 Recommended Books

### For Beginners
- **"Python for Data Analysis"** by Wes McKinney
  - Author created pandas
  - Excellent for data manipulation

- **"Hands-On Machine Learning"** by Aurélien Géron
  - Best ML book for practitioners
  - Covers scikit-learn and TensorFlow

- **"Introduction to Machine Learning with Python"** by Andreas Müller & Sarah Guido
  - Written by scikit-learn core developer
  - Great for beginners

### For Intermediate
- **"The Hundred-Page Machine Learning Book"** by Andriy Burkov
  - Concise and complete
  - Great reference

- **"Machine Learning Engineering"** by Andriy Burkov
  - MLOps and production
  - Real-world practices

- **"Designing Data-Intensive Applications"** by Martin Kleppmann
  - System design for data
  - Architecture patterns

### For Advanced
- **"Deep Learning"** by Ian Goodfellow
  - Comprehensive deep learning
  - Mathematical foundations

- **"Pattern Recognition and Machine Learning"** by Christopher Bishop
  - Mathematical depth
  - ML theory
