# Week 2: Data Pipeline

Welcome to Week 2! This week you'll learn to build robust data processing pipelines - the foundation of any ML system.

## 🎯 Week 2 Goals

By the end of this week, you will:

✅ Load data from multiple sources (CSV, JSON, SQL, APIs)
✅ Validate data quality and schema
✅ Handle missing values and outliers
✅ Engineer meaningful features
✅ Build preprocessing pipelines
✅ Prevent data leakage

## 📚 Learning Path

###Day 1-2: Data Loading & Validation
1. **1-data-loading.py** (3-4 hours)
   - Load from CSV, JSON, SQL
   - Handle different formats
   - Data profiling

2. **2-data-validation.py** (3-4 hours)
   - Schema validation
   - Type checking
   - Constraint validation

### Day 3-4: Feature Engineering & Preprocessing
3. **3-feature-engineering.py** (3-4 hours)
   - Feature creation
   - Encoding categoricals
   - Feature interactions

4. **4-preprocessing.py** (3-4 hours)
   - Scaling and normalization
   - Missing value imputation
   - sklearn Pipelines

### Day 5: Project
5. **data_pipeline.py** (4-6 hours)
   - End-to-end pipeline
   - Production-ready code
   - Portfolio piece

## 🚀 Quick Start

```bash
cd learning-prototype/week-2-data-pipeline
python 1-data-loading.py
```

## 📊 Key Concepts

- **Data Validation**: Ensure data quality before training
- **Feature Engineering**: Create predictive features
- **Data Leakage**: Prevent test data from influencing training
- **sklearn Pipelines**: Chain preprocessing steps

## ✅ Success Criteria

- [ ] Can load data from various sources
- [ ] Understand schema validation
- [ ] Master feature engineering
- [ ] Build sklearn pipelines
- [ ] Prevent all data leakage
- [ ] Complete week project
