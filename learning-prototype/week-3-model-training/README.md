# Week 3: Model Training & Evaluation

Welcome to Week 3! This week you'll learn to train, evaluate, and optimize machine learning models.

## 🎯 Week 3 Goals

By the end of this week, you will:

✅ Train multiple ML algorithms
✅ Evaluate model performance
✅ Perform cross-validation
✅ Tune hyperparameters
✅ Select the best model
✅ Build a complete training pipeline

## 📚 Learning Path

### Day 1-2: Training & Evaluation
1. **1-model-training.py** (3-4 hours)
   - Train classification/regression models
   - Model parameters
   - Model persistence

2. **2-evaluation.py** (3-4 hours)
   - Accuracy, precision, recall, F1
   - ROC curves and AUC
   - Confusion matrices

### Day 3-4: Validation & Optimization
3. **3-cross-validation.py** (3-4 hours)
   - K-fold cross-validation
   - Stratified CV
   - Time series CV

4. **4-tuning.py** (3-4 hours)
   - Grid search
   - Random search
   - Bayesian optimization

### Day 5: Project
5. **training_pipeline.py** (4-6 hours)
   - End-to-end training
   - Model comparison
   - Best model selection

## 🚀 Quick Start

```bash
cd learning-prototype/week-3-model-training
python 1-model-training.py
```

## 🎓 Key Concepts

- **Model Training**: Fit models to data
- **Evaluation Metrics**: Measure performance
- **Cross-Validation**: Robust evaluation
- **Hyperparameter Tuning**: Optimize performance
- **Model Selection**: Choose the best model
