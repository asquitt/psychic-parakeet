# Week 4: MLOps & Production

Welcome to Week 4! This week you'll learn to deploy and monitor ML models in production.

## 🎯 Week 4 Goals

By the end of this week, you will:

✅ Track experiments with MLflow
✅ Deploy models as APIs
✅ Monitor model performance
✅ Detect data and model drift
✅ Build CI/CD pipelines
✅ Create production-ready systems

## 📚 Learning Path

### Day 1-2: Experiment Tracking & Deployment
1. **1-experiment-tracking.py** (4-5 hours)
   - MLflow setup
   - Log parameters and metrics
   - Model registry

2. **2-deployment.py** (4-5 hours)
   - FastAPI/Flask servers
   - Model serving
   - API endpoints

### Day 3-5: Monitoring & CI/CD
3. **3-monitoring.py** (4-5 hours)
   - Performance tracking
   - Drift detection
   - Alerting

4. **4-ci-cd.py** (6-8 hours)
   - Automated testing
   - GitHub Actions
   - Deployment automation

### Day 5+: Project
5. **production_system/** (6-8 hours)
   - Complete production system
   - All MLOps practices
   - Portfolio showcase

## 🚀 Quick Start

```bash
cd learning-prototype/week-4-mlops
python 1-experiment-tracking.py
```

## 🎓 Key Concepts

- **Experiment Tracking**: Version and compare models
- **Model Deployment**: Serve predictions
- **Monitoring**: Track production performance
- **Drift Detection**: Detect data changes
- **CI/CD**: Automate testing and deployment
